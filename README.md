# Telecom Customer Churn Analytics: Strategic Retention Dashboard

## Descripcion del Proyecto
Este producto analitico es una aplicacion interactiva desarrollada en Python y desplegada bajo la infraestructura de Streamlit. El sistema tiene como objetivo diagnosticar y examinar de forma exhaustiva la perdida de clientes en el sector de las telecomunicaciones mediante tecnicas de limpieza, transformacion y visualizacion de datos. 

A traves de un procesamiento con Pandas y NumPy, y la implementacion de Programacion Orientada a Objetos, la plataforma descubre patrones criticos, correlaciones operativas y perfiles de riesgo financiero, orientandose especificamente a la toma de decisiones estrategicas de retencion.

## Tecnologias Utilizadas
* Core Engine: Python 3.x
* Data Wrangling: Pandas Framework y NumPy Arrays
* Data Viz: Plotly Express, Seaborn Graphics y Matplotlib
* UI Framework: Streamlit Architecture y Session State Management

## Estructura de la Suite Analitica
* Modulo 1: Home: Contextualizacion del caso de estudio, ficha tecnica del autor y mapa de infraestructura tecnologica.
* Modulo 2: Carga de Datos: Ingesta dinamica de la matriz con tecnicas de coercion de tipos, resolucion de anomalias de codificacion e indicadores descriptivos automatizados.
* Modulo 3: Analisis Exploratorio (EDA) Interactivo: Visualizaciones vectoriales nativas en el navegador que segmentan la fuga de manera demografica, por tipo de servicios y comportamiento financiero.
* Modulo 4: Gestion de Reportes (POO): Suite de auditoria basada en la clase DataAnalyzer que ejecuta un desglose de 10 items estadisticos, filtros parametricos multiselect y conclusiones analiticas directas.
