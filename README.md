# Telecom Customer Churn Analytics: Strategic Retention Dashboard

## Descripcion del Proyecto
Este producto analitico es una aplicacion interactiva desarrollada integramente en Python y desplegada bajo la infraestructura de Streamlit. El sistema tiene como objetivo diagnosticar y examinar de forma exhaustiva la perdida de clientes (Churn) en el sector de las telecomunicaciones mediante tecnicas avanzadas de limpieza, transformacion y visualizacion de datos. 

A traves de un procesamiento riguroso con Pandas y NumPy, y la implementacion de Programacion Orientada a Objetos (POO), la plataforma descubre patrones criticos, correlaciones operativas y perfiles de riesgo financiero sin recurrir a modelos de caja negra, orientandose especificamente a la toma de decisiones estrategicas de retencion.

## Tecnologias Utilizadas
* **Core Engine:** Python 3.x (Estructuras avanzadas y POO)
* **Data Wrangling:** Pandas Framework & NumPy Arrays
* **Data Viz:** Plotly Express, Seaborn Graphics & Matplotlib
* **UI Framework:** Streamlit Architecture & Session State Management

## Estructura de la Suite Analitica
1. **Modulo 1: Home:** Contextualizacion del caso de estudio, ficha tecnica del autor y mapa de infraestructura tecnologica.
2. **Modulo 2: Carga de Datos:** Ingesta dinamica de la matriz con tecnicas de coercion de tipos, resolucion de anomalias de codificacion (latin-1) e indicadores descriptivos automatizados.
3. **Modulo 3: Analisis Exploratorio (EDA) Interactivo:** Visualizaciones vectoriales nativas en el navegador que segmentan la fuga de manera demografica, por tipo de servicios y comportamiento financiero.
4. **Modulo 4: Gestion de Reportes (POO):** Suite de auditoria basada en la clase customizada DataAnalyzer que ejecuta un desglose exhaustivo de 10 items estadisticos minimos, filtros parametricos multiselect y conclusiones analiticas directas.
